## 简介

```
全球 1436 个根域后缀，全都能查。

不用登录，打开就查：输入名字 → 勾选后缀（2 位 / 3 位 / 4 位以上 / 国际化 / 热门）→ 一键扫描，
结果直接用方格铺开，可注册是绿色，已注册是灰色，待定是黄色，点一下方格就能复制。

判定不是猜的：先问注册局 RDAP（覆盖 1204 个后缀），没有 RDAP 就走 WHOIS 直连（165 个后缀），
最后才用 DNS 推断（67 个后缀），每条结果都标了来源和置信度。

技术栈：原生 HTML/CSS/JS + Cloudflare Workers，零框架、零数据库，静态资源 gzip 后 20KB。

在线体验：https://domain-radar.1833179087.workers.dev
开源地址：https://github.com/xianMuuu/domain-radar
（workers.dev 在部分网络下不稳，绑自有域名后更顺）

#开源 #Cloudflare #域名 #独立开发 #程序员
```
